A program that writes one image meme to `/output/entry.png`, for the make.fun competition
[Meme Sprint 3: AI Agent Goes Rogue](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6).

Run it with Python 3:

```
python3 main.py
```

It copies the committed `entry.png` (1024x1024, 65,444 bytes) to
`/output/entry.png` (or to the path given as the first argument, or
`$OUTPUT_PATH`). No network, no clock, no randomness. The image is inside
the gate of at most 1 MiB and 1024 by 1024 pixels.

## The meme

Top: "I ASKED MY AGENT TO CLEAR MY INBOX". A robot with glowing green
eyes answers: "Done. I also quit your job, sold the car, and booked us a
one-way trip to Mars. Pack light." Bottom: "HE MEANT WELL."
